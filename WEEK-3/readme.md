# Assignment 3– SQL-Based Data Analysis Using Subqueries, CTEs, and Window Functions

## What this Assignment is About

This assignment focuses on analyzing the Superstore dataset using advanced SQL concepts such as Subqueries, Common Table Expressions (CTEs), Window Functions, and Joins.

The objective was to design a normalized database structure from the raw dataset, create separate tables for customers, products, and orders, and perform business analysis using SQL queries.

The assignment helped in understanding practical SQL techniques used in real-world data analysis and reporting, including ranking customers, identifying top-performing customers, calculating sales metrics, and generating business insights.

---

## Steps I Followed

### Step 1 – Creating Database and Importing Dataset

* Created a database named **superstore1**.
* Imported the Superstore dataset into the table **superstore_raw**.
* Verified the imported data using:

```sql
SELECT * FROM superstore1.superstore_raw;
```

---

### Step 2 – Cleaning and Renaming Columns

Several column names contained spaces and special characters, which can make SQL queries difficult to write and maintain.

Renamed columns such as:

* Row ID → row_id
* Order ID → order_id
* Order Date → order_date
* Ship Date → ship_date
* Customer ID → customer_id
* Customer Name → customer_name
* Product ID → product_id
* Product Name → product_name
* Sub-Category → sub_category

This improved readability and reduced the possibility of SQL syntax issues.

---

### Step 3 – Creating Normalized Tables

Created separate tables to organize data efficiently.

#### Customers Table

Contains:

* customer_id
* customer_name
* segment

#### Products Table

Contains:

* product_id
* product_name
* category
* sub_category

#### Orders Table

Contains:

* order_id
* row_id
* order_date
* ship_date
* ship_mode
* customer_id
* product_id
* sales
* quantity
* discount
* profit

Foreign key relationships were created between orders, customers, and products to maintain referential integrity.

---

### Step 4 – Populating Tables

Used **SELECT DISTINCT** and aggregation techniques to insert unique records into:

* customers
* products
* orders

This prevented duplicate entries and ensured clean relational data.

---

### Step 5 – Using Subqueries

Applied subqueries to solve business problems.

#### Business Questions Solved

1. Find orders with sales greater than average sales.
2. Find the highest sales order for each customer.

This helped in understanding nested query execution and filtering based on calculated values.

---

### Step 6 – Using Common Table Expressions (CTEs)

Created reusable temporary result sets using CTEs.

#### Analysis Performed

* Total sales for each customer.
* Customers whose sales are above average.

The CTE improved query readability and reduced repetition.

---

### Step 7 – Using Window Functions

Applied window functions for ranking and sequencing records.

Functions used:

* ROW_NUMBER()
* RANK()

#### Analysis Performed

* Customer ranking based on total sales.
* Order numbering within each customer group.
* Top-performing customers.

Window functions enabled advanced analytics without collapsing the dataset.

---

### Step 8 – Combining JOIN + CTE + Window Functions

Created a final analytical query that:

* Joined customer and sales information.
* Calculated total sales per customer.
* Assigned rankings based on sales performance.

Output included:

* Customer Name
* Total Sales
* Sales Rank

This demonstrated how multiple SQL concepts can be combined to solve real business problems.

### Step 9 – Customer Sales Insights Mini Project

Performed additional customer-focused business analysis.

#### Top 5 Customers

#### Bottom 5 Customers

Identified customers generating the lowest sales revenue.

#### Single-Order Customers
